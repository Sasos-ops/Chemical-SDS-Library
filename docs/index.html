# Chemical SDS Library A professional, searchable repository for Safety Data Sheets (SDS), Material Safety Data Sheets (MSDS), and Technical Data Sheets (TDS) used for operational and maintenance chemicals. ## Overview This repository stores the most current chemical documentation required for safe use, handling, and maintenance across workshop, utility, and operational environments. browsable landing page: [docs/index.html](docs/index.html) - Open the repository files directly from the GitHub file list - All document links on the landing page open in a new browser tab for easier review ## Document types - SDS: Safety Data Sheet - MSDS: Material Safety Data Sheet - TDS: Technical Data Sheet ## How to use 1. Open the library landing page at `docs/index.html`. 2. Use the search box to find a product or document type. 3. Click any document to open it in a new tab. 4. Keep the file naming convention consistent when adding new records. ## Naming convention Use a simple and consistent naming format: ```text Product-Name_DocumentType_Revision.pdf ``` Examples: - `Loctite_243_SDS.PDF` - `Unispec_Rust_Remover_TDS.pdf` - `Diesel_SDS.PDF` ## Maintenance notes - Add new documents to the correct category and keep names consistent. - Update the landing page if a new PDF is added to the repository. - Keep PDF files readable and in a standard format for fast access. ## GitHub Pages This repository is ready for a simple GitHub Pages landing page experience. Once Pages is enabled from the repository settings, the `docs/index.html` page can be served as a polished public document library. ## Contact For document updates, corrections, or new chemical records, contact the repository maintainer.
