# Chemical-SDS-Library
Chemical inventory repository containing Safety Data Sheets (SDS), Material Safety Data Sheets (MSDS), and Technical Data Sheets (TDS) for operational and maintenance chemicals.

## Live library
Browse the library at https://sasos-ops.github.io/Chemical-SDS-Library/ — documents open as PDFs in a new tab.

PDFs must be placed in the `docs/` folder (the GitHub Pages source) and listed in `docs/index.html`.
