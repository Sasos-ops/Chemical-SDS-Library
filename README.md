# Chemical SDS Library

A browsable library of Safety Data Sheets (SDS), Material Safety Data Sheets (MSDS) and Technical Data Sheets (TDS) for operational and maintenance chemicals (52 documents).

## Quick start

**[Open the library website](https://sasos-ops.github.io/Chemical-SDS-Library/)** — searchable, grouped by category, and every document opens in a new browser tab.

> The site is served by GitHub Pages (Settings → Pages → Deploy from branch, root folder). GitHub's README cannot force links to open in a new tab; use the website above, or middle-click / Ctrl+click the links below.

## Repository structure

- `index.html` – landing page that links to all documents (`target="_blank"`).
- `*.pdf` – the SDS / MSDS / TDS documents.
- `README.md` – this overview.
